# 調理穴位圖

可旋轉的 3D 全息線框人體穴位圖。依中藥處方的調理方向（健脾補氣、安神定悸、疏肝解壓、溫陽利濕）挑選 13 個保健穴位，點選即可查看位置、找法、按法，並搭配按壓計時器。

## 使用方式

線上瀏覽：**https://moonus6v6.github.io/acupoint-map/**

也可以下載後直接用瀏覽器開啟 `index.html`，不需要安裝或建置。

- 拖曳旋轉人體，滾輪或 +／− 按鈕縮放
- 點選人體上的亮點或右側清單，鏡頭會轉到該穴位
- 依調理目標篩選穴位
- 按壓計時器：左右兩側的穴位會提醒換邊

## 技術說明

- 單一 HTML 檔案，3D 使用 [three.js](https://threejs.org/)（r149，從 jsDelivr 載入）
- 人體模型不使用外部模型檔：以約 80 個肌肉與骨骼形狀的符號距離場（SDF）平滑融合雕塑，再用 Surface Nets 在瀏覽器中即時轉成網格
- 比例依 8 頭身、身高 1.80 m 設定；軀幹、左右手臂、左右腿分組融合，避免手臂與軀幹黏連
- 穴位座標以「寸」換算後自動吸附到體表

## 注意

本頁僅供保健參考，不能取代醫師診斷、服藥與回診。懷孕或可能懷孕時，三陰交禁按，腹部穴位請先諮詢醫師。
